# Specs

Specs are the behavior contract for Habit Compass. Do not implement non-trivial behavior without an existing or updated spec.

Use `_templates` for new specs and keep MVP behavior under `specs/mvp`.

Authentication is the exception to the MVP-folder convention: `/specs/auth` is the canonical
development guide for auth, legal acceptance, RevenueCat subscription identity, Android auth
deep links, and immediate account deletion. It supersedes older MVP auth/account lifecycle/legal
guidance where they conflict.
